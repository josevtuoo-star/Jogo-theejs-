PC

  • W A S D mover (trotar) · Mouse olhar
  • Shift correr · X andar devagar · Espaço pular
  • 1 mãos livres · 2 faca · 3 revólver · rodinha troca
  • Revólver: botão direito mirar · clique atirar · R recarregar
  • F perto de caixas .357: pegar munição
  • Espaço perto de obstáculo: passar por cima / subir / escalar
  • Pulando contra uma borda alta: agarra e fica pendurado
  • W na escada de mão: subir
  • C / Ctrl agachar (correndo: deslizar)
  • C antes de cair no chão: rolar
  • Q / E inclinar (espiar)
  • Clique soco / golpe de faca (cliques seguidos = combo)
  • Segurar clique carrega o golpe forte, soltar desfere
  • F abrir/fechar porta
  • L lanterna · V câmera
  • Na água: Ctrl mergulha, Espaço sobe
  • Esc pausar

Android

  • Lado esquerdo joystick (pouco = andar, mais = trotar)
  • TROCAR mãos livres → faca → revólver
  • Revólver: MIRAR (liga/desliga) · ATIRAR · RECARR.
  • Arraste o dedo sobre ATIRAR/MIRAR para mirar sem soltar
  • Lado direito arrastar para olhar
  • Joystick no limite = correr
  • PULAR perto de obstáculo: escalar
  • AGACHAR correndo: deslizar
  • USAR aparece perto de portas
  • Botão de ataque: toques seguidos = combo · segurar = golpe forte

Controle

  • Analógicos mover / olhar
  • A pular/escalar · B agachar/deslizar
  • L3 ou LT correr · RT atacar (segurar = forte)
  • Revólver: LT mirar · RT atirar · ↓ recarregar
  • LB / RB inclinar
  • X usar/porta · ↑ lanterna · Y câmera
  • ← mãos/faca/revólver · → andar devagar
